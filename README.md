# NanyVet

Sitio web de Clínica Veterinaria NanyVet preparado para publicar en Vercel.

## Uso rápido en Vercel

- Framework: Next.js
- Build command: `npm run build`
- Install command: `npm install`
- Variable recomendada: `NEXT_PUBLIC_SITE_URL` con la URL final del sitio.

Esta versión está pensada como sitio público editable desde código. El panel de administración no se incluye en esta primera publicación para mantener el despliegue simple. Si más adelante se requiere edición online de textos/fotos, puede agregarse Supabase u otro backend.
